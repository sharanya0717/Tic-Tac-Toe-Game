# Tic Tac Toe Game in C++

## Description
A console-based Tic Tac Toe game developed using C++.  
This project demonstrates core programming concepts such as loops, arrays, functions, conditional statements, and file handling.

The game provides an interactive gameplay experience with dynamic board updates, score tracking, AI opponent mode, and game history storage.

---

## Features

- Player vs Player mode
- Player vs Computer mode
- Dynamic game board display
- Win/Loss detection
- Draw detection
- Replay functionality
- Scoreboard tracking
- Input validation
- Random AI move generation
- Game history saved using file handling
